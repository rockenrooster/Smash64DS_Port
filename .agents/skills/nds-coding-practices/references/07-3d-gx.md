# 07 — GX submission and compositing

DS videoGL is a small hardware interface, not desktop OpenGL. Establish VRAM, viewport, projection, model/vector matrices, texture/palette ownership, clear plane and a submission owner. Source values must fit native formats: matrix/scalar `f32` has 12 fractional bits, `v16` is signed 4.12 ([-8,8)), `t16` is signed 12.4, and packed normals are signed 10-bit components with 9 fractional bits. Scaling, spaces and winding require a derived conversion, not casts.

## Preserve alpha through draw state

Use [05](05-vram-memory-and-assets.md) for format/texel rules. A texture-alpha material must also select a compatible polygon equation:

| Setting | Consequence |
|---|---|
| `POLY_MODULATION` | Texture and polygon alpha contribute to output alpha. The usual cutout/texture-alpha route when it matches the intended equation. White vertex RGB avoids unintended tint for unlit textures. |
| `POLY_DECAL` | Texture alpha mixes texture RGB with vertex RGB; output alpha follows polygon alpha rather than the texture-alpha cutout equation. A correct alpha texture can therefore fill its quad. Do not map an N64 macro containing “DECAL” to this flag by name. |
| `POLY_ALPHA(31)` | Full polygon alpha; texture alpha can still make holes or translucency in modulation. |
| `POLY_ALPHA(1..30)` | Polygon translucency; not a repair for a missing per-texel mask. |
| `POLY_ALPHA(0)` | **Wireframe, not invisible.** For genuinely zero intended output, omit geometry emission while preserving required update/state/event work. |

Bind/restore the complete texture, palette, polygon mode, alpha, ID, culling, depth and texture-parameter state before the primitive that consumes it. Track invalidation after raw hardware writes or external renderers. Do not infer active state from the source material name alone.

`GL_BLEND`, `GL_ALPHA_TEST`, and `glAlphaFunc()` change **global raster registers**, not stored per-material FIFO attributes. Establish a compatible frame/raster-phase policy; toggling them between queued meshes does not attach separate settings to those meshes. Global texturing is similar: use a per-polygon no-texture binding for untextured draws rather than toggling global texturing around queued geometry. Preserve sticky status flags when managing `DISP3DCNT`.

Enable blending for required graded compositing. It cannot reconstruct alpha erased during conversion/upload; binary cutout coverage alone does not require graded blending. Alpha-test threshold is 0–31 and rejects results at or below the threshold; 31 rejects everything. Use zero as the ordinary cutout baseline and test the actual output-alpha path. Incompatible source thresholds need preclassified/baked compatible masks or another validated native treatment, not per-mesh global-register toggles. The pinned header's old 0–15 parameter comment is not the register's width.

## Depth, ordering and layer interactions

Separate cutout and blended recipes. Reorder only when source-equivalent. For manually ordered translucent geometry use the correct swap/sort mode; automatic sorting is not arbitrary back-to-front correctness. Polygon IDs affect translucent overlap: same-ID surfaces can suppress required blending. IDs are finite (0–63); allocate by intended overlap/identity, not blindly one ID per effect or per triangle. Check rear-plane ID as well.

Do not universally enable translucent depth writes. Test foreground/background overlap, equal-depth surfaces, camera movement, self-overlap, winding and near/far-plane behavior. Moving a quad toward the camera is not a general transparency repair. Culling fixes need correct winding and transform parity, not “disable culling everywhere.”

Use a transparent clear plane where lower 2D layers must remain visible and configure the 2D priorities/blend destinations. An opaque clear is valid for a standalone full-3D scene; it is not a universal template.

## Geometry capacity, lists and lifetime

Budget both polygon RAM (2048 entries) and vertex RAM (6144 entries), plus per-scanline raster work and clipping overhead. Quads use four vertices; strips reuse vertices differently. Projection/texture stacks have one saved level; model/vector stack has 31 usable levels. Avoid deep source-hierarchy push/pop assumptions. Check error/status counters rather than explaining every missing polygon as overflow.

Native lists contain a leading **payload word count**, then packed commands/parameters. Validate count, command arity, alignment, capacity, and DMA-visible storage before calling libnds. The pinned `glCallList()` flushes payload, waits for existing DMA activity, uses DMA0, then waits for transfer completion. It is not a renderer-completion fence; textures and palettes can remain in use. Do not add redundant per-draw flush/copy passes without measuring them.

`glFlush()` requests a buffer swap; it is not a universal CPU/GPU/VRAM release fence. Retire command buffers after their reader finishes and textures after the frame's raster consumer finishes, under the project's actual pipeline.

## Required rendering checks

For changed texture/material paths, show native output over contrasting backgrounds: a hole, opaque black, graded alpha, two overlapping sprites, an occluder, alpha animation, palette/material swaps, camera motion and scene reload. Compare uploaded bytes and submitted state when pixels disagree. The [cutout example](../examples/gx_cutout.c) is a direct-color smoke test, not an N64 material compiler or a visual certification.
