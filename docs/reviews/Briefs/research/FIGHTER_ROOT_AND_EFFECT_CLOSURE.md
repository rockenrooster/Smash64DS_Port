# Fighter bodies, attachment programs and effect children

Source anchors: S02/S11 and R18/R52/R61/R64/R65/R71/R83/R84. This is an
implementation contract for remaining gaps, not a claim that every named owner
is currently absent. R04 is the supplied concrete Link dispatch repair.

## A body becoming invisible is often whole-owner rejection

A source motion may hide the normal model and expose replacement model parts.
The native owner must represent the complete ordered binding set in that state.
Skipping an unfamiliar binding or forcibly clearing hide flags destroys the
source contract. An attachment can use a foreign asset/image whose root offsets,
epochs, lights and vertex tables are not interchangeable with the body image.

Derive programs from readonly source motion commands and DL-pair consumers, then
validate them independently of the generator's own manifest. The following is a
proposed **generation record**, not a declaration of the current Python API:

```text
program:
  source_status_and_modelpart_signature
  ordered_bindings[]:
    source_file_id, root_offset, source_joint, parent_binding
    pre_child_or_post_child_phase, source_material_owner
    geometry_owner, runtime_table_owner, light_preamble_owner
    palette_slot, cross_matrix_policy
  reachable_detail_variants
  restoration_and_interruption_transitions
```

The generator must put the same closure into ordinary generated declarations and
NitroFS owner images. Changing only a header can leave the shipped image missing
the new roots/state sequences. Update producer dependencies, image ABI only when
layout truly changes, validators and staged outputs coherently. Preserve source
transform-only ancestors and DL-pair ordering around vertex loads.

## Yoshi

Inspect `247_YoshiMain.c`, model-part arrays, source motion scripts and the actual
DL-pair draw routine. Build signatures for Catch/Throw, SpecialN/SpecialAirN,
EggThrow and AppearR/AppearL, including their completion and interruptions. Native
model replacement must bind the source tongue/jaw/egg geometry, not make the entire
ordinary body artificially visible. Both detail images must have equivalent
reachable content even if their geometry differs.

The four reports include multiple owners: Yoshi body, thrown egg, shell breakup,
captured-target egg and entry egg. Close the source trigger -> descriptor ->
resource -> update -> native submit -> pixels chain for each. Sharing assets does
not make their constructors or lifetimes identical. Preserve victim restoration,
release and collision behavior.

## Link

The source SpecialN program already knows foreign owner 2 for boomerang geometry.
R04 makes its disabled-Kirby helper agree with the existing Kirby-enabled helper
for runtime tables AND light preambles. Check the actual configuration before
attributing the user's failure. Test high/low, no boomerang in hand, held boomerang,
throw, return, missed catch, ground/air transitions and canonical restoration.

Do not reimplement Catch or CopyLink because an old document says they were
missing. Spin's grounded body/sword program and airborne effect-only case require
separate engagement. An entry column uses different source materials from Spin.

## Samus

Existing tests identify MorphUnfold and MorphBall programs 2/3 with source roots
0x8158/0x8708. Source parallel helper scripts hide the body, set joint 6 to the
morph part and restore it. The root programs are not absent. Exercise human
RollF/RollB, cliff-escape siblings and ground/air Bomb; a level-3 CPU window that
never enters them does not test them.

Separate body morph from Bomb weapon/explosion, and charging orb from detached
shot. Repair the first bad program, image or live-joint binding without making all
Samus parts visible. A source no-Z charging overlay cannot be safely “fixed” by
changing the depth of every launched shot.

## Pikachu, common electric damage and Saffron children

Enumerate complete EFDesc/weapon/particle child families, not just visible bodies.
Thunder includes head/trail/strike/shock obligations; an electric victim effect
attaches to victim joints; an attack telegraph is not the same as an impact spark.
Saffron monsters are stage-item actors and must preserve their source attributes,
attack and retirement callbacks rather than borrow an arbitrary Poké Ball body.

For each absent effect, determine which of these is actually missing:

```text
source trigger or linked real maker
required root/script/frame in the AOT closure
runtime owner lookup and source-link admission
correct live attachment transform and material frame
resource lifetime through the last child consumer
```

The current converter, some weak-body imports, Captain owners/DLHEAD1 bridge,
Kirby Cutter and Pikachu ground-jolt roots already contain newer work. Revalidate
specific code and generated manifests before adding any of them again.

## Tests that establish more than compilation

A source-derived state matrix must cover ground/air, both facings, detail modes,
completion, interruption, reuse and reentry. On the natural path, record positive
program/child engagement and actual output on the exact candidate. Test foreign
table bounds against the actual image, not only the host mock. Preserve gameplay
and source timing; budget changes require matched performance evidence. Native
rejection is still an unclosed missing-content failure.
