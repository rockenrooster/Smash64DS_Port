**Copy capability inventory.** Derive donor/identity rows, copy status dispatch, hat/modelpart selectors, articles, motion/material/voice roots and source gain/loss/transfer rules. Ten implementation TUs, eleven non-self donors and twelve identity rows are different categories; actual special equivalence/sharing comes from the source, not those counts. Luigi's implementation sharing does not erase its source identity row.

**Copied powers and hats.** Qualify every legal source donor outcome: capture/copy, visibly correct modelpart/material, copied special/child ownership, loss/taunt/damage conditions and return to base. Test relevant mirror/transfer rules from source. A hat is a source modelpart swap—not automatically an extra scene-graph graft or an item-hand attachment.

**Cutter and Stone.** Natural ground/air transitions retain correct body/transformed representation, source collision/resistance/end rules, cutter projectile/trails and impact cues. Do not assume Stone invulnerability or armor from another game.

**Campaign Kirby Team.** P2-6 owns team population; this unit supplies source copy capabilities and valid per-instance/native data through replacement. The team-specific source asset root is not an optional VS-only donor shortcut.
