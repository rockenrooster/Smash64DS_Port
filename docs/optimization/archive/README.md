# Optimization archive

This directory contains only the few retired architectural/campaign references
that still explain a durable design decision or are cited by another retained
historical document.

Uncited per-task Claude/Task memos were removed during the 2026-09-02 docs
cleanup. A small number remain only because retained historical documents still
cite them. Durable measurements, rejected experiments, and corrections are owned
by `../../PERF_LEDGER.md` and `../../PORTING.md`; parallel task narratives must
not become a second source of current truth.

Do not add new per-task optimization documents here. Put reproducible performance
results in `../../PERF_LEDGER.md`, chronological project history in
`../../PORTING.md`, and current work only on `../../P2_EXECUTION_BOARD.md`.
